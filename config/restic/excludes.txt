# --- Flatpak application state ----------------------------------------

# history lives there and does not restore from the phone. But Flatpak apps
# keep large caches in the same tree, and none of the globs above catch them:
# the directory is `cache`, not `.cache`.
#
# Electron apps (Signal, Obsidian, Proton Mail) are the bulk of it — several
# hundred MB of GPU and code cache that regenerates on first launch.
