# Bundle: river — a complete Wayland tiling session.
#
# Opt-in per machine via machines/<profile>.bundles. NOT in common.txt: the
# desktop runs KDE with Hyprland alongside (ADR-0002) and does not want a
# third session's worth of packages until that question is settled
# (06-backlog/open-questions.md §2).
#
# river is a compositor and nothing else — no bar, no launcher, no lock, no
# notifications, no display management. Everything below is a piece the
# desktop environment was quietly providing. That is the real cost of a
# minimal compositor, and it is worth seeing written down as a list.
#
# Plasma REMAINS the default session. This is a second entry in the display
# manager, chosen at login. That is not a nicety — river comes from a
# single upstream with no Fedora-side maintenance, and principle #2 says the
# college machine keeps a working fallback. See ADR-0002's pattern.
#
# All names verified present in Fedora 44's own repos on 2026-08-23 — no
# COPR, which is precisely why this is river and not Hyprland.

# --- the compositor ---------------------------------------------------
# river-classic, NOT river. This distinction is the whole ballgame.
#
# river went "non-monolithic" at 0.4.x: the compositor and the window manager
# split into separate programs. Fedora's `river` package is that new 0.4.8,
# which needs a compatible external WM and does nothing on its own — it
# refuses to read an init file at all:
#
#   error: The init file … contains the string "riverctl".
#   This river version (0.4.8) does not support riverctl, you may
#   wish to install river-classic instead.
#
# Everything anyone has written about river — riverctl, the init script, tags,
# rivertile, every guide and dotfiles repo — is river-CLASSIC. That is the
# continuation of the project people mean.
#
# Installed `river` first (2026-08-23) on the strength of `dnf info river`
# showing 0.4.8 in Fedora's own repos. Verifying a package EXISTS is not the
# same as verifying it is the thing you think it is; the version number ran
# continuously straight across an architectural break. Cost: one black screen
# and a hard power-off.
river-classic

# --- bar, launcher, notifications -------------------------------------
waybar                    # bar; the `tray` module is what makes nm-applet work
fuzzel                    # launcher — wlroots-native, no toolkit baggage

# SwayNotificationCenter (binary: swaync), NOT mako.
#
# mako is the usual minimal choice and would be the right one if notifications
# only had to appear and disappear. But a notification INDICATOR on the bar was
# a stated requirement, and mako has no waybar module, no history and no
# do-not-disturb UI — you would be polling `makoctl` from a shell script.
# swaync ships a real waybar module with an unread count, a panel with history,
# and a DND toggle. Same job, one fewer bodge.
SwayNotificationCenter

# --- session plumbing -------------------------------------------------
# Each of these replaces something Plasma did without being asked.
swaybg                    # wallpaper
swayidle                  # lock-on-idle and screen blanking
swaylock                  # the lock screen itself
wlogout                   # power menu: shutdown/reboot/suspend/hibernate/logout/lock
kanshi                    # display profiles, applied on hotplug — the projector case
wlr-randr                 # one-off output tweaks when kanshi isn't the answer

# --- laptop hardware keys ---------------------------------------------
# Nothing handles these for you here; the keybinds in config/river/init call them.
brightnessctl

# --- on-screen display -------------------------------------------------
# wob — the amber overlay gauges bin/osd feeds (tier 2 of its display
# chain; ADR-0023 era). Session-agnostic: currently started by
# config/hypr/hyprland.conf, adoptable by river's init unchanged. Tier 1
# (swayosd) is deliberately NOT here — it comes from the erikreider/swayosd
# COPR, which dnf cannot enable from a package list; bin/osd degrades
# through wob to plain notifications when it is absent, so a rebuild
# without the COPR still answers every key.
wob

# --- screenshots ------------------------------------------------------
grim                      # capture
slurp                     # region selection
swappy                    # annotate and save — optional, but the reason
                          # screenshots are useful for coursework

# --- wallpaper previews ------------------------------------------------
# bin/river-wallpaper renders a PNG thumbnail cache for fuzzel's per-entry
# icons (fuzzel loads only PNG/SVG, and raw 4K JPEGs would be absurd).
# The picker degrades to text-only without it, but previews were asked for
# by name (2026-08-25), so it is declared rather than optional.
ImageMagick

# --- audio and media keys ---------------------------------------------
# wpctl comes from wireplumber, and the volume/mute keybindings in
# config/river/init plus waybar's `wireplumber` module both call it. Present on
# a KDE spin already — declared anyway, because "it came with the desktop
# environment" stops being true the moment a rebuild installs a minimal system
# and this bundle on top. Audited 2026-08-24.
wireplumber

# playerctl — bound to XF86AudioMedia in config/river/init. The binding is
# already wrapped in `|| true` so a missing playerctl costs one key rather
# than the session, which is why this went unnoticed.
playerctl

# --- clipboard --------------------------------------------------------
# cliphist adds history on top of wl-clipboard. wl-clipboard itself moved to
# packages/common.txt on 2026-08-24: this file used to note it was "already
# installed (nvim uses wl-copy)", which is an observation about the current
# machine, not a declaration that survives a rebuild.
cliphist

# --- tray applets -----------------------------------------------------
# Plasma had these built in. In waybar they are separate processes in the tray.
network-manager-applet    # nm-applet — the wifi picker. Campus wifi needs this
blueman                   # blueman-applet — bluetooth

# --- portals and theming ----------------------------------------------
xdg-desktop-portal-wlr    # SCREEN SHARING. Presentations are a stated use of
                          # this machine; without this, sharing shows a blank
xdg-desktop-portal-gtk    # file picker dialogs (already installed, listed for
                          # completeness — a rebuild must not omit it)
# qt6ct — FALLBACK ONLY on this machine, and bin/river-session probes before
# using it.
#
# The original note here said "Qt apps outside Plasma otherwise ignore the
# theme entirely and render in default grey". That is true where Plasma is not
# installed. Here it is: this is the Fedora KDE spin, and forcing
# QT_QPA_PLATFORMTHEME=qt6ct actively BREAKS the KDE apps — Dolphin, Ark,
# Okular and Gwenview read ~/.config/kdeglobals for colours, icons and fonts,
# and qt6ct overrides that with a config nothing has filled in. Dolphin then
# renders grey in river while looking correct in Plasma, from identical files.
#
# plasma-integration's `kde` platform theme is preferred instead, keeping
# kdeglobals as one source of truth across both sessions. qt6ct earns its place
# only for a future machine running river with no Plasma underneath.
qt6ct

# Luv — the icon theme neon-sprawl names in themes/neon-sprawl/icon-theme
# (ADR-0027). Installs /usr/share/icons/Luv, and THAT is the string gsettings
# and kdeglobals want: the package name is not the theme name, and a wrong
# string there fails silently by falling back rather than erroring. Confirmed
# with `dnf repoquery -l`, not assumed.
#
# Chosen over the two other in-repo candidates on 2026-08-27, from `dnf list`
# rather than from memory. Candy (/usr/share/icons/Candy) is vivid pink/purple
# gradients on every icon — exactly the "ornament at content weight" failure
# ADR-0021's grammar exists to prevent; a folder is not more important than the
# file you are looking for. Papirus is better maintained with far better
# coverage, but reads as a good neutral dark set rather than a DIFFERENT one
# from breeze-dark, so it would be a package installed to change nothing.
#
# COVERAGE IS THE RISK, not correctness: a sparse icon theme falls through to
# hicolor and renders generic placeholders. If that bites, the swap is
# papirus-icon-theme-dark plus a one-line edit to themes/neon-sprawl/icon-theme.
#
# No cursor equivalent exists. Fedora 44 packages only adwaita, bluecurve,
# breeze and oxygen cursors — all neutral, none neon — so themes/*/cursor is
# deliberately absent and the pointer stays breeze_cursors 24 in both themes.
# Anything neon would be a hand-installed asset with no update story, which is
# ADR-0016 territory, on the college machine, for a mouse pointer.
luv-icon-theme

# --- session prerequisites Plasma happened to supply ------------------
# These two were listed under "deliberately NOT here" on the grounds that they
# are "already installed". That was an observation about this machine on this
# day, not a declaration — and both are load-bearing enough that discovering
# them missing on a rebuilt system is a bad afternoon. Promoted 2026-08-24.
#
# polkit-kde-authentication-agent provides the binary config/river/init execs
# at /usr/libexec/polkit-kde-authentication-agent-1. WITHOUT AN AGENT, anything
# needing authorisation fails with no prompt and no error at all.
polkit-kde
# gnome-keyring — Secret Service provider. Signal, Element and everything using
# libsecret store their credentials through it. Chosen over kwallet precisely
# because it does not assume a Plasma session is running; see the note in
# config/river/init.
gnome-keyring

# The Qt half of the theme switch (ADR-0027). bin/hypr-theme's apply_desktop()
# calls plasma-apply-colorscheme, plasma-apply-cursortheme and kwriteconfig6 —
# so Dolphin, Okular, Ark, Gwenview and Plasma itself follow the session theme.
#
# Same promotion argument as polkit-kde and gnome-keyring above: "it came with
# the KDE spin" is an observation about this machine on this day, not a
# declaration that survives a rebuild. Without these the theme switch does not
# error — apply_desktop() guards every call with `command -v` — it just silently
# skips the Qt half, which is the failure shape this repo keeps being bitten by.
#
# Package names from `rpm -qf $(command -v …)` on the machine, not from memory:
# the binaries and the packages that carry them share no name at all.
#
# kf6-kconfig is here because Fedora 44 ships no plasma-changeicons (checked
# with `command -v`), so the KDE half of the icon theme goes in via
# kwriteconfig6 writing kdeglobals directly.
plasma-workspace          # plasma-apply-colorscheme, plasma-apply-cursortheme
kf6-kconfig               # kwriteconfig6 — the icon-theme lever

#                   all in packages/common.txt — wanted on every machine, not
#                   just the ones running river. This bundle assumes them.
# pipewire          base install on both distros; wireplumber above is the part
#                   this session actually calls (wpctl), so only it is declared.
